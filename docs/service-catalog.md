## Plan Tiers

| Tier            | Code                | Who Gets It                                                                        |
| --------------- | ------------------- | ---------------------------------------------------------------------------------- |
| **Free**        | `free`              | All new users by default                                                           |
| **Trial**       | `trial` (synthetic) | Auto-activated for 14 days on new free accounts — full Pro features, capped quotas |
| **Pro Monthly** | `pro_monthly`       | Paid monthly subscribers                                                           |
| **Pro Annual**  | `pro_annual`        | Paid annual subscribers (same limits as monthly)                                   |
| **Agency**      | `agency`            | Highest tier — teams, LinkedIn, unlimited everything                               |

**Trial mechanics** (`src/lib/middleware/require-plan.ts:99-140`): `getPlanContext()` checks `user.trialEndsAt`. When the trial is active, `effectivePlan = "trial"` — this gives full Pro tool access with capped quotas (50 AI text, 25 images, 20 posts, 1 X account). Trial is handled transparently by the plan gates — no special route-level code needed.

**Grace period:** If `planExpiresAt` has passed (payment failure), the user is treated as free.

## AI Quota Enforcement

### Text Quota (`src/lib/services/ai-quota-atomic.ts`)

- **Method:** `tryConsumeAiQuota(userId, weight)` — atomic PostgreSQL decrement via `UPDATE ... WHERE used + weight <= limit`
- **Weights:** Most services = 1×, Agentic/PDF/YouTube = 5×
- **Fallback:** When base quota exhausts, falls back to `ai_quota_grants` rows (admin-issued top-ups)
- **Reset:** Counters reset per calendar month via `ai-counter-rollover` cron

### Image Quota (`src/lib/services/ai-image-quota-atomic.ts`)

- **Method:** `tryConsumeImageQuota(userId, weight)` — atomic decrement, weighted by model cost (1–5)
- **Fallback:** No grant fallback for images
- **Release:** `releaseImageQuota()` on generation failure to prevent billing leaks

### Admin Quota Grants

- Route: `POST /api/admin/users/[userId]/grant-quota/`
- Range: 1–10,000 units
- Schema: `ai_quota_grants` table with `amount`, `remaining`, `grantedBy`, `reason`
- **No self-service top-up exists** — grants are admin-only

## Background Workers (BullMQ)

All workers run on Railway (`pnpm run worker`). They process jobs for all tiers — the plan gates run at job creation time (in the API route), not at processing time.

| **Schedule Processor**       | `schedule-queue`       | Publishes posts to X at scheduled time, handles recurrence, re-gates at publish time |

| **X Tier Refresher**         | `x-tier-refresh-queue` | Scans stale X accounts, refreshes Premium tier, detects downgrades                   |

| **PDF Thread Processor**     | `pdfThreadQueue`       | Async PDF → chunk → summarize → moderate → persist                                   |
| **YouTube Thread Processor** | `youtubeThreadQueue`   | Async YT download → transcribe → thread gen → moderate → persist                     |

## Free Tier Blocklist (Quick Reference)

Free users cannot access:

- ❌ Threads, video/GIF, URL-to-thread, YouTube-to-thread, PDF-to-thread
- ❌ Discovery (YouTube search, X Trends)
- ❌ Viral score, best times, competitor analysis, analytics export
- ❌ Voice profile, variant generator, reply generator, bio optimizer, inbox reply
